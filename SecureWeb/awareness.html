Stay Safe in the Digital World

Learn simple cybersecurity practices to protect your accounts, devices, data and online identity.

Essential Cybersecurity Practices

Follow these security practices to reduce common cybersecurity risks.

🔑 Strong Passwords

Use long, unique passwords for your accounts. Avoid using the same password everywhere.

🔐 Enable MFA

Use multi-factor authentication to add an extra layer of protection to your accounts.

🎣 Identify Phishing

Check emails, messages and links carefully before clicking or sharing information.

🔄 Keep Software Updated

Install security updates and patches to reduce vulnerabilities.

📶 Use Wi-Fi Safely

Avoid entering sensitive information on untrusted public networks.

💾 Backup Important Data

Keep backups of important files so they can be recovered if something goes wrong.

💻 Secure Your Devices

Use screen locks, security software and regular updates on your devices.

🧠 Watch for Social Engineering

Verify unusual requests before sharing information or taking action.

Quick Security Checklist

Use this checklist to review your basic security habits.

  • ✓ I use strong and unique passwords.
  • ✓ I use multi-factor authentication where available.
  • ✓ I check links before opening them.
  • ✓ I keep my software updated.
  • ✓ I avoid sharing sensitive information unnecessarily.
  • ✓ I maintain backups of important files.
  • ✓ I verify suspicious requests before responding.
